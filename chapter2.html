Chapter 2: DHTML and CSS

Detailed notes based on Punjabi University Web Development syllabus.

1. Introduction to DHTML

1.1 What is DHTML?

DHTML stands for Dynamic HyperText Markup Language. It is not a separate programming language. It is a combination of HTML, CSS and JavaScript used to create interactive and dynamic web pages.

1.2 Components of DHTML

  • HTML: Defines the structure and content of a webpage.
  • CSS: Controls the appearance, layout and styling of webpage elements.
  • JavaScript: Adds behaviour and interactivity to webpage elements.
  • DOM: Allows scripts to access and modify HTML elements.

1.3 Working of DHTML

DHTML works by combining HTML, CSS and JavaScript. HTML creates webpage elements, CSS styles them, and JavaScript changes their content or appearance when an event occurs.

For example, when a user clicks a button, JavaScript can change the text or background colour of a webpage without reloading the entire page.

1.4 Features of DHTML

  • Creates interactive web pages.
  • Changes webpage content dynamically.
  • Allows modification of styles and positioning.
  • Supports event handling.
  • Creates animation and visual effects.
  • Can show or hide webpage elements.
  • Improves user interaction and experience.

1.5 Advantages of DHTML

  • Makes websites more interactive.
  • Allows content updates without a full page reload.
  • Reduces unnecessary page navigation.
  • Supports dynamic menus and animations.
  • Provides a better user experience.

1.6 Limitations of DHTML

  • Complex effects can be difficult to develop.
  • Browser differences may affect behaviour.
  • Excessive scripting can affect performance.
  • JavaScript must be enabled for many interactive features to work.

1.7 Combining HTML, CSS and JavaScript

DHTML combines three important technologies to create dynamic web pages.

<!DOCTYPE html>
<html>
<head>
<style>
    p {
        color: blue;
    }
</style>
</head>
<body>

<p id="demo">Hello Student</p>

<button onclick="changeText()">
    Click Me
</button>

<script>
function changeText() {
    document.getElementById("demo").innerHTML =
    "Welcome to DHTML";
}
</script>

</body>
</html>

Explanation: HTML creates the paragraph and button. CSS makes the paragraph blue. JavaScript changes the paragraph text when the button is clicked.

2. Dynamic Content Manipulation

2.1 Meaning of Dynamic Content

Dynamic content is webpage content that can change automatically or in response to user actions. JavaScript is commonly used to update webpage content.

2.2 Changing HTML Content

JavaScript can change the text or HTML inside an element using the innerHTML property.

<p id="message">Old Message</p>

<script>
document.getElementById("message").innerHTML =
"New Message";
</script>

2.3 Changing CSS Styles Dynamically

JavaScript can modify CSS styles of HTML elements through the style property.

<p id="text">Hello World</p>

<script>
document.getElementById("text").style.color = "red";
document.getElementById("text").style.fontSize = "25px";
</script>

2.4 Creating Interactive Web Pages

An interactive webpage responds to user actions such as clicking buttons, moving the mouse or entering information in forms.

DHTML uses JavaScript events and DOM manipulation to make webpages interactive.

2.5 Event Handling

Event handling is the process of detecting and responding to actions performed by users or the browser.

Common events include:

  • click: Occurs when an element is clicked.
  • mouseover: Occurs when the pointer moves over an element.
  • mouseout: Occurs when the pointer leaves an element.
  • keydown: Occurs when a keyboard key is pressed.
  • change: Occurs when an input value changes.
  • load: Occurs when a page or resource finishes loading.

2.6 Event Handling Example

<button id="btn">Click Me</button>

<script>
document.getElementById("btn").addEventListener(
    "click",
    function() {
        alert("Button Clicked!");
    }
);
</script>

The addEventListener() method attaches an event handler to an HTML element.

3. DOM and BOM

3.1 Document Object Model (DOM)

DOM stands for Document Object Model. It represents an HTML document as a tree of objects. JavaScript uses the DOM to access, modify, add or remove webpage elements.

3.2 DOM Tree

A DOM tree represents the structure of an HTML document. The document is the root, and HTML elements are represented as nodes connected in a tree-like structure.

3.3 DOM Manipulation

DOM manipulation means changing the structure, content or attributes of HTML elements using JavaScript.

3.4 Selecting Elements

// Select by ID
document.getElementById("demo");

// Select by class
document.getElementsByClassName("box");

// Select by tag
document.getElementsByTagName("p");

// Select using CSS selector
document.querySelector(".box");

3.5 Modifying Elements

document.getElementById("demo").innerHTML =
"Updated Content";

document.getElementById("demo").style.color =
"blue";

3.6 Creating and Removing Elements

JavaScript can create new HTML elements using createElement() and add them using appendChild(). Elements can be removed using remove().

let newPara = document.createElement("p");

newPara.textContent = "New Paragraph";

document.body.appendChild(newPara);

// Remove an element
newPara.remove();

3.7 Browser Object Model (BOM)

BOM stands for Browser Object Model. It allows JavaScript to interact with the browser window and browser-related features outside the webpage document.

3.8 Common BOM Objects

  • window: Represents the browser window.
  • location: Provides information about the current page URL.
  • history: Provides access to browser session history.
  • navigator: Provides information about the browser.
  • screen: Provides information about the user's screen.

3.9 BOM Example

// Display browser window width
console.log(window.innerWidth);

// Display current page URL
console.log(location.href);

// Display browser information
console.log(navigator.userAgent);

3.10 DOM vs BOM

  • DOM: Used to access and manipulate webpage content and elements.
  • BOM: Used to interact with browser window and browser features.

4. Dynamic Styles and Positioning

4.1 Dynamic Styles

Dynamic styling means changing the appearance of HTML elements during runtime using JavaScript. It allows a webpage to respond to user actions.

4.2 Changing Styles Using JavaScript

<p id="demo">Welcome to CSS</p>

<script>
let element = document.getElementById("demo");

element.style.color = "blue";
element.style.backgroundColor = "lightyellow";
element.style.fontSize = "24px";
</script>

4.3 Dynamic Positioning

Dynamic positioning means changing the location of an element on a webpage using CSS properties and JavaScript.

CSS position properties include:

  • static: Default position of an element.
  • relative: Positions an element relative to its normal position.
  • absolute: Positions an element relative to its nearest positioned ancestor.
  • fixed: Positions an element relative to the browser window.
  • sticky: Switches between relative and fixed positioning depending on scrolling.

4.4 Positioning Example

<div id="box">Moving Box</div>

<style>
#box {
    position: relative;
    left: 20px;
    top: 10px;
}
</style>

5. Animation Effects

5.1 Introduction to Animation

Animation is the process of creating movement or visual changes in webpage elements over a period of time. CSS animations can change properties such as colour, size and position.

5.2 CSS Transitions

A transition smoothly changes a CSS property from one value to another when a change occurs.

<style>
.box {
    width: 100px;
    height: 100px;
    background: blue;
    transition: width 1s;
}

.box:hover {
    width: 200px;
}
</style>

<div class="box"></div>

5.3 CSS Keyframe Animation

The @keyframes rule defines the stages of an animation. The animation property applies the animation to an element.

<style>
@keyframes changeColor {
    from {
        background: blue;
    }
    to {
        background: purple;
    }
}

.box {
    width: 100px;
    height: 100px;
    animation: changeColor 3s infinite alternate;
}
</style>

<div class="box"></div>

5.4 Uses of Animation

  • Highlighting important information.
  • Creating loading effects.
  • Making buttons interactive.
  • Improving visual appearance of websites.

6. Dynamic Menus and Navigation

6.1 Meaning

A dynamic menu is a navigation menu that changes its appearance or behaviour in response to user actions. JavaScript and CSS are commonly used to create dynamic menus.

6.2 Example of a Dynamic Menu

<button onclick="toggleMenu()">
    Menu
</button>

<ul id="menu" style="display:none;">
    <li>Home</li>
    <li>About</li>
    <li>Contact</li>
</ul>

<script>
function toggleMenu() {
    let menu = document.getElementById("menu");

    if (menu.style.display === "none") {
        menu.style.display = "block";
    } else {
        menu.style.display = "none";
    }
}
</script>

Explanation: When the user clicks the Menu button, JavaScript checks the current display property and shows or hides the menu.

7. Show and Hide Elements

7.1 Introduction

Show and hide functionality allows webpage elements to become visible or invisible according to user actions. It is commonly used in menus, FAQs and information panels.

7.2 Using display Property

<p id="info">This is important information.</p>

<button onclick="hideText()">Hide</button>
<button onclick="showText()">Show</button>

<script>
function hideText() {
    document.getElementById("info").style.display = "none";
}

function showText() {
    document.getElementById("info").style.display = "block";
}
</script>

7.3 Difference Between display and visibility

  • display: none: Hides the element and removes its space from the layout.
  • visibility: hidden: Hides the element but keeps its space in the layout.

8. Real-Time Content Updates

8.1 Meaning

Real-time content updates mean changing webpage information immediately when new data or user input becomes available, without requiring a complete page reload.

8.2 Example Using JavaScript

<input type="text" id="name"
       placeholder="Enter your name">

<p id="output"></p>

<script>
document.getElementById("name").addEventListener(
    "input",
    function() {
        document.getElementById("output").textContent =
        "Hello " + this.value;
    }
);
</script>

Explanation: Whenever the user types in the input field, the paragraph updates immediately.

8.3 Applications

  • Live search suggestions.
  • Instant form feedback.
  • Live notifications.
  • Updating counters and information.

9. Introduction to CSS

9.1 What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to control the presentation and appearance of HTML documents.

CSS controls colours, fonts, spacing, borders, backgrounds and the layout of webpage elements.

9.2 Advantages of CSS

  • Separates webpage design from HTML content.
  • Provides a consistent design across multiple pages.
  • Reduces repeated styling code.
  • Makes website maintenance easier.
  • Improves control over webpage layout.

9.3 CSS Syntax

A CSS rule consists of a selector and a declaration block. Each declaration contains a property and a value.

selector {
    property: value;
}

Example:

p {
    color: blue;
    font-size: 18px;
}

Explanation:

  • p: Selector that targets paragraph elements.
  • color: CSS property.
  • blue: Property value.
  • font-size: Property used to set text size.

10. Types of CSS

10.1 Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute. It applies styling to that particular element.

<p style="color: red; font-size: 20px;">
    This is Inline CSS.
</p>

Advantages: Quick to apply and useful for styling a single element.

Disadvantages: Difficult to maintain when many elements need the same styling.

10.2 Internal CSS

Internal CSS is written inside the style element in the head section of an HTML document. It is useful when styling a single webpage.

<head>
<style>
h1 {
    color: blue;
    text-align: center;
}
</style>
</head>

<body>
<h1>Welcome to CSS</h1>
</body>

10.3 External CSS

External CSS is written in a separate file with a .css extension. The HTML document connects to it using the link element.

HTML file:

<link rel="stylesheet" href="style.css">

style.css file:

body {
    background-color: lightblue;
}

h1 {
    color: navy;
}

Advantages: The same stylesheet can be used by multiple webpages, making maintenance easier.

10.4 Difference Between CSS Types

  • Inline: Written inside an HTML element.
  • Internal: Written inside the style element in the HTML head.
  • External: Written in a separate .css file.

11. CSS Selectors

11.1 What are CSS Selectors?

CSS selectors are patterns used to select HTML elements that need to be styled. They tell the browser which elements should receive a particular CSS rule.

11.2 Element Selector

An element selector selects all HTML elements of a particular tag name.

p {
    color: green;
}

h1 {
    text-align: center;
}

This example styles all paragraphs green and aligns all h1 headings to the centre.

11.3 Class Selector

A class selector selects HTML elements that have a particular class attribute. A class selector begins with a dot (.) in CSS.

.highlight {
    background-color: yellow;
    color: black;
}

HTML:

<p class="highlight">
    Important Information
</p>

A class can be applied to multiple HTML elements.

11.4 ID Selector

An ID selector selects an element with a particular ID attribute. An ID selector begins with a hash symbol (#).

#heading {
    color: purple;
    font-size: 30px;
}

HTML:

<h1 id="heading">Web Development</h1>

An ID should be unique within an HTML document.

11.5 Difference Between Element, Class and ID Selectors

  • Element selector: Selects elements using their tag name, such as p or h1.
  • Class selector: Selects elements using a class name and starts with a dot.
  • ID selector: Selects an element using an ID and starts with #.
