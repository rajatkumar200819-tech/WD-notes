Chapter 4: JavaScript Fundamentals and DOM

Detailed notes based on Punjabi University Web Development syllabus.

1. Introduction to JavaScript

1.1 What is JavaScript?

JavaScript is a high-level scripting language used to make web pages interactive and dynamic. It can change webpage content, respond to user actions, validate forms and perform calculations.

1.2 Features of JavaScript

  • Lightweight scripting language.
  • Supports dynamic webpage content.
  • Works with HTML and CSS.
  • Supports event handling.
  • Can manipulate the DOM.
  • Runs in modern web browsers.

1.3 Uses of JavaScript

  • Form validation.
  • Interactive buttons and menus.
  • Dynamic content updates.
  • Animations and effects.
  • Calculations and data processing.

1.4 Adding JavaScript to HTML

JavaScript can be added to an HTML document using the script element.

<script>
alert("Hello World");
</script>

JavaScript can also be placed in an external file.

<script src="script.js"></script>

2. JavaScript Variables and Data Types

2.1 Variables

A variable is a named container used to store data in a program.

JavaScript provides three commonly used ways to declare variables:

  • var: Older way of declaring a variable. It has function scope.
  • let: Declares a block-scoped variable that can be reassigned.
  • const: Declares a block-scoped variable that cannot be reassigned.
let name = "Aman";
var age = 18;
const college = "Punjabi University";

2.2 JavaScript Data Types

Data types define the kind of value stored in a variable.

  • String: Text values.
  • Number: Numeric values.
  • Boolean: true or false values.
  • Undefined: A variable declared but not assigned a value.
  • Null: Represents an intentional absence of value.
  • BigInt: Represents very large integers.
  • Symbol: Represents unique identifiers.
  • Object: Stores collections of related data.
let student = "Aman";
let marks = 85;
let passed = true;
let result;
let data = null;

2.3 Checking Data Types

The typeof operator is used to identify the data type of a value.

let age = 18;
console.log(typeof age);

let name = "Aman";
console.log(typeof name);

3. Operators and Expressions

3.1 What are Operators?

Operators are symbols used to perform operations on values and variables.

3.2 Arithmetic Operators

  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • % Modulus (remainder)
  • ** Exponentiation
  • ++ Increment
  • -- Decrement
let a = 10;
let b = 3;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);

3.3 Assignment Operators

Assignment operators assign or update values in variables.

let x = 10;

x += 5;
x -= 2;
x *= 2;
x /= 2;

3.4 Comparison Operators

  • == Equal value
  • === Equal value and type
  • != Not equal value
  • !== Not equal value or type
  • > Greater than
  • < Less than
  • >= Greater than or equal to
  • <= Less than or equal to

3.5 Logical Operators

  • && Logical AND
  • || Logical OR
  • ! Logical NOT

3.6 Expressions

An expression is a combination of values, variables and operators that produces a result.

let result = 10 + 20 * 2;

4. Control Structures

4.1 Introduction

Control structures determine the order in which statements are executed in a program.

4.2 if Statement

The if statement executes a block of code when a condition is true.

let age = 18;

if (age >= 18) {
    console.log("Eligible");
}

4.3 if-else Statement

The if-else statement executes one block when the condition is true and another when it is false.

let marks = 45;

if (marks >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}

4.4 else-if Ladder

It is used to check multiple conditions one after another.

let marks = 75;

if (marks >= 80) {
    console.log("Grade A");
} else if (marks >= 60) {
    console.log("Grade B");
} else {
    console.log("Grade C");
}

4.5 switch Statement

The switch statement selects one block of code from multiple possible cases.

let day = 2;

switch (day) {
    case 1:
        console.log("Monday");
        break;
    case 2:
        console.log("Tuesday");
        break;
    default:
        console.log("Other Day");
}

5. Loops in JavaScript

5.1 Introduction

Loops are used to execute a block of code repeatedly while a condition is satisfied.

5.2 for Loop

The for loop is generally used when the number of repetitions is known.

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

5.3 while Loop

The while loop executes as long as its condition is true.

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

5.4 do-while Loop

The do-while loop executes its block at least once before checking the condition.

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

5.5 Difference Between Loops

  • for: Best suited when the number of repetitions is known.
  • while: Checks the condition before executing the loop body.
  • do-while: Checks the condition after executing the loop body.

6. Functions and Scope

6.1 What is a Function?

A function is a reusable block of code designed to perform a particular task.

6.2 Function Declaration

function greet() {
    console.log("Hello Student");
}

greet();

6.3 Parameters and Arguments

Parameters are variables listed in a function definition. Arguments are actual values passed when the function is called.

function add(a, b) {
    return a + b;
}

let result = add(10, 20);
console.log(result);

6.4 Return Statement

The return statement sends a value back from a function.

6.5 Function Scope

Scope determines where a variable can be accessed in a program.

  • Global scope: A variable declared outside functions can generally be accessed throughout its accessible script.
  • Function scope: A variable declared with var inside a function is accessible within that function.
  • Block scope: Variables declared using let and const inside a block are accessible within that block.
let globalName = "Aman";

function example() {
    let localName = "Student";
    console.log(globalName);
    console.log(localName);
}

7. Arrays and Objects

7.1 Arrays

An array is a data structure used to store multiple values in a single variable. Array indexing starts from zero.

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits[0]);
console.log(fruits.length);

7.2 Common Array Methods

  • push(): Adds an element at the end.
  • pop(): Removes the last element.
  • shift(): Removes the first element.
  • unshift(): Adds an element at the beginning.
  • includes(): Checks whether a value exists.

7.3 Objects

An object stores related data in key-value pairs called properties. Objects can also contain functions called methods.

let student = {
    name: "Aman",
    age: 18,
    course: "CSE"
};

console.log(student.name);
console.log(student.course);

8. String Manipulation and Mathematical Operations

8.1 Strings

A string is a sequence of characters used to represent text. Strings can be written using single quotes, double quotes or backticks.

let message = "Hello JavaScript";

console.log(message.length);
console.log(message.toUpperCase());
console.log(message.toLowerCase());
console.log(message.includes("JavaScript"));
console.log(message.slice(0, 5));

8.2 String Concatenation

Concatenation means joining two or more strings using the + operator.

let first = "Hello";
let second = "Student";

let result = first + " " + second;
console.log(result);

8.3 Template Literals

Template literals use backticks and allow variables to be inserted using ${}.

let name = "Aman";

console.log(`Welcome ${name}`);

8.4 Mathematical Operations

JavaScript provides the Math object for performing common mathematical operations.

console.log(Math.round(4.6));
console.log(Math.floor(4.9));
console.log(Math.ceil(4.1));
console.log(Math.sqrt(25));
console.log(Math.pow(2, 3));
console.log(Math.max(10, 20, 30));
console.log(Math.min(10, 20, 30));

9. Type Conversion and Comments

9.1 Type Conversion

Type conversion means changing a value from one data type to another.

9.2 Explicit Conversion

Explicit conversion is performed by the programmer using conversion functions.

let num = Number("25");
let text = String(100);
let value = Boolean(1);

console.log(num);
console.log(text);
console.log(value);

9.3 Implicit Conversion

Implicit conversion happens automatically when JavaScript converts a value to another type during an operation.

console.log("5" + 2);
console.log("5" - 2);

9.4 JavaScript Comments

Comments explain code and are ignored during execution.

// Single-line comment

/*
Multi-line
comment
*/

10. Introduction to DOM

10.1 What is DOM?

DOM stands for Document Object Model. It represents an HTML document as a tree of objects. JavaScript uses the DOM to access and modify webpage elements.

10.2 DOM Tree

The DOM tree represents the hierarchical structure of an HTML document. Each HTML element is represented as a node.

10.3 Selecting Elements

JavaScript provides different methods for selecting HTML elements.

// Select element by ID
document.getElementById("demo");

// Select using a CSS selector
document.querySelector(".box");

// Select all matching CSS selectors
document.querySelectorAll("p");

10.4 Modifying Content

JavaScript can change the text or HTML content of an element.

document.getElementById("demo").textContent =
"Updated Text";

document.getElementById("demo").innerHTML =
"<b>Bold Text</b>";

10.5 Modifying Attributes

Attributes provide additional information about HTML elements. JavaScript can change them using setAttribute().

document.getElementById("photo")
.setAttribute("alt", "Student Photo");

10.6 Creating and Removing Elements

let para = document.createElement("p");

para.textContent = "New Paragraph";

document.body.appendChild(para);

// Remove the element
para.remove();

11. JavaScript Events and Event Handling

11.1 What is an Event?

An event is an action or occurrence detected by the browser, such as clicking a button, pressing a key or submitting a form.

11.2 Common JavaScript Events

  • click: When an element is clicked.
  • mouseover: When the mouse pointer enters an element.
  • mouseout: When the mouse pointer leaves an element.
  • keydown: When a keyboard key is pressed.
  • input: When the value of an input changes.
  • change: When an input value is changed and committed.
  • submit: When a form is submitted.

11.3 Event Handling Using HTML

<button onclick="alert('Hello')">
Click Me
</button>

11.4 Event Listeners

The addEventListener() method attaches an event handler to an element without placing the event code directly inside the HTML tag.

document.getElementById("btn")
.addEventListener("click", function() {
    alert("Button clicked");
});

11.5 Event Propagation

Event propagation describes how an event travels through elements in the DOM tree.

  • Capturing: The event travels from outer elements towards the target element.
  • Bubbling: The event travels from the target element towards outer elements. Bubbling is the default behaviour for many events.

11.6 Event Propagation Example

document.getElementById("parent")
.addEventListener("click", function() {
    console.log("Parent clicked");
});

document.getElementById("child")
.addEventListener("click", function() {
    console.log("Child clicked");
});

12. Form Validation

12.1 What is Form Validation?

Form validation is the process of checking user input before accepting or submitting form data. It helps ensure that the entered information follows required rules.

12.2 Types of Validation

  • HTML validation: Uses attributes such as required, minlength, maxlength and type.
  • JavaScript validation: Uses scripts to check user input and display custom messages.

12.3 HTML Form Validation Example

<form>
    <input type="email" required
           placeholder="Enter email">

    <input type="password" required
           minlength="6"
           placeholder="Password">

    <button type="submit">Submit</button>
</form>

12.4 JavaScript Form Validation Example

<form id="myForm">
    <input id="username" type="text"
           placeholder="Enter name">

    <button type="submit">Submit</button>
</form>

<script>
document.getElementById("myForm")
.addEventListener("submit", function(event) {

    let name = document.getElementById("username").value;

    if (name.trim() === "") {
        event.preventDefault();
        alert("Please enter your name");
    }
});
</script>

The preventDefault() method stops the form's normal submission when the name is empty.

13. Dynamic Content Updates

13.1 Meaning

Dynamic content updates allow webpage information to change in response to user actions or program instructions without reloading the complete page.

13.2 Example

<p id="result">Original Text</p>

<button id="update">Update Text</button>

<script>
document.getElementById("update")
.addEventListener("click", function() {

    document.getElementById("result").textContent =
    "Content Updated Successfully";

});
</script>

13.3 Applications

  • Live search results.
  • Instant form feedback.
  • Interactive dashboards.
  • Dynamic notifications.
  • Updating information on a webpage.
