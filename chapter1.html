Chapter 1: Internet and HTML

Complete study notes based on Punjabi University Web Development syllabus.

1. Internet and World Wide Web

1.1 Introduction to Internet

The Internet is a worldwide network of interconnected computer networks. It allows computers and devices to communicate and exchange information using standard communication protocols.

1.2 Internet Addressing

Internet addressing is the process of identifying devices and resources connected to the Internet.

  • IP Address: A numerical address that identifies a device on a network.
  • IPv4: Uses a 32-bit address, such as 192.168.1.1.
  • IPv6: Uses a 128-bit address to support a much larger number of devices.
  • Domain Name: A human-readable website name, such as example.com.

1.3 ISP (Internet Service Provider)

An ISP is an organization or company that provides Internet access to users. It may also provide email, web hosting and other Internet services.

1.4 Types of Internet Connections

  • Dial-up: Uses a telephone line and modem to connect to the Internet.
  • DSL: Provides Internet through telephone lines.
  • Cable: Uses cable television infrastructure.
  • Fiber Optic: Uses optical fibers to provide high-speed Internet.
  • Satellite: Uses communication satellites to provide connectivity.
  • Mobile Broadband: Uses cellular networks such as 4G and 5G.

1.5 Introduction to WWW

WWW stands for World Wide Web. It is a collection of interconnected web pages and resources that can be accessed through the Internet using a web browser.

1.6 Web Browser

A web browser is application software used to access, retrieve and display web pages. Examples include Google Chrome, Mozilla Firefox, Microsoft Edge and Safari.

1.7 Web Server

A web server is a computer or software that stores website files and delivers web pages to browsers when requested.

1.8 URL Structure

URL stands for Uniform Resource Locator. It is the address used to locate a resource on the Internet.

https://www.example.com/about.html
  • https: Protocol or scheme.
  • www: Subdomain.
  • example.com: Domain name.
  • about.html: Resource path.

1.9 HTTP and HTTPS

HTTP stands for HyperText Transfer Protocol. It is used for communication between web browsers and web servers.

HTTPS is the secure version of HTTP. It uses encryption to protect data exchanged between a browser and a server.

1.10 DNS (Domain Name System)

DNS translates human-readable domain names into IP addresses so that computers can locate the correct servers on the Internet.

1.11 Web Applications

A web application is software that runs through a web browser and allows users to perform tasks online. Examples include online email services, document editors and banking applications.

1.12 Tools for Website Creation

  • Text Editors: Used to write HTML, CSS and JavaScript code. Example: Visual Studio Code.
  • Web Browsers: Used to view and test websites.
  • Developer Tools: Used to inspect and debug webpages.
  • Image Editors: Used to prepare images and graphics for websites.
  • Local Servers: Used to test websites on a local computer.

2. HTML Basics

2.1 Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure web pages.

2.2 HTML Structure and Syntax

An HTML document contains elements written using tags. Most elements have an opening tag, content and a closing tag.

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>Welcome to HTML.</p>
</body>
</html>

2.3 HTML Document Structure

  • DOCTYPE: Declares the document as HTML5.
  • html: Root element of the document.
  • head: Contains metadata and page information.
  • title: Defines the browser tab title.
  • body: Contains the visible webpage content.

2.4 HTML Elements and Tags

A tag is a keyword written inside angle brackets. An element generally includes an opening tag, content and a closing tag.

<p>This is a paragraph.</p>

2.5 HTML Attributes

Attributes provide additional information about HTML elements. They are written inside the opening tag.

<a href="https://example.com">
Visit Website
</a>

Here, href is an attribute that specifies the link destination.

2.6 HTML Comments

Comments are notes written in source code. They are not displayed on the webpage.

<!-- This is an HTML comment -->

2.7 Character Entities and Special Symbols

HTML entities are used to display reserved characters and special symbols.

  • &lt; displays less-than (<).
  • &gt; displays greater-than (>).
  • &amp; displays ampersand (&).
  • &nbsp; represents a non-breaking space.
  • &copy; displays copyright (©).

3. Text and Lists

3.1 Headings and Subheadings

HTML provides six heading levels, from h1 to h6. The h1 element represents the highest-level heading, while h6 represents the lowest-level heading.

<h1>Main Heading</h1>
<h2>Subheading</h2>
<h3>Smaller Heading</h3>

3.2 Paragraphs and Line Breaks

The p tag creates a paragraph. The br tag inserts a line break.

<p>This is a paragraph.</p>
First Line<br>
Second Line

3.3 Text Formatting Tags

  • strong: Indicates important text.
  • em: Indicates emphasized text.
  • b: Displays bold text.
  • i: Displays italic text.
  • u: Underlines text.
  • mark: Highlights text.
  • small: Displays smaller text.
  • del: Represents deleted text.
  • sup: Displays superscript text.
  • sub: Displays subscript text.

3.4 Ordered Lists

An ordered list displays items in a numbered or ordered sequence. It uses ol and li tags.

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

3.5 Unordered Lists

An unordered list displays items with bullets. It uses ul and li tags.

<ul>
    <li>Apple</li>
    <li>Mango</li>
</ul>

3.6 Definition Lists

A definition list displays terms and their descriptions. It uses dl, dt and dd tags.

<dl>
    <dt>HTML</dt>
    <dd>Markup language for web pages.</dd>
</dl>

3.7 Nested Lists

A nested list is a list placed inside another list item. It is useful for displaying subcategories.

<ul>
    <li>Programming
        <ul>
            <li>C</li>
            <li>JavaScript</li>
        </ul>
    </li>
</ul>

3.8 Organizing Content with Proper Structure

HTML provides semantic elements that help organize webpage content meaningfully.

  • header: Introductory content or page heading.
  • nav: Navigation links.
  • main: Main content of the page.
  • section: A thematic group of content.
  • article: Independent content.
  • footer: Footer information.

4. Links and Graphics

4.1 Creating Hyperlinks

Hyperlinks allow users to navigate from one webpage or resource to another. The a tag creates hyperlinks.

<a href="https://example.com">
Visit Example
</a>

4.2 Absolute URLs

An absolute URL contains the complete address of a resource, including its protocol and domain name.

https://www.example.com/about.html

4.3 Relative URLs

A relative URL specifies a resource location relative to the current webpage or document.

about.html
images/photo.jpg

4.4 Anchor Links

Anchor links navigate to a particular section of the same page or another page using an element ID.

<a href="#contact">Go to Contact</a>

<h2 id="contact">Contact Us</h2>

4.5 Adding Images to HTML Pages

The img tag is used to add images to a webpage. It is a void element and does not require a closing tag.

<img src="photo.jpg"
     alt="A sample photo"
     width="300">

4.6 Image Attributes

  • src: Specifies the image location.
  • alt: Provides alternative text.
  • width: Specifies image width.
  • height: Specifies image height.

4.7 Image Formats

  • JPEG/JPG: Commonly used for photographs.
  • PNG: Supports transparency and lossless compression.
  • GIF: Supports simple animations.
  • SVG: Vector format that scales without losing quality.
  • WebP: Modern format offering efficient image compression.

4.8 Figure and Figcaption

The figure element groups media content, while figcaption provides a caption or description.

<figure>
    <img src="flower.jpg" alt="Flower">
    <figcaption>A beautiful flower</figcaption>
</figure>

4.9 Image Maps

An image map allows different areas of a single image to act as separate clickable links. It uses map and area elements.

<img src="workplace.jpg"
     usemap="#mymap"
     alt="Workplace">

<map name="mymap">
    <area shape="rect"
          coords="20,20,150,100"
          href="page.html"
          alt="Open page">
</map>

5. Tables in HTML

5.1 Introduction to HTML Tables

HTML tables are used to organize and display data in rows and columns. They are useful for presenting information such as student records, marksheets and timetables.

5.2 Table Structure

The main HTML table elements are:

  • table: Creates the table.
  • tr: Defines a table row.
  • th: Defines a heading cell.
  • td: Defines a normal data cell.

5.3 Creating a Table

<table border="1">
    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>
    <tr>
        <td>Aman</td>
        <td>85</td>
    </tr>
    <tr>
        <td>Rahul</td>
        <td>90</td>
    </tr>
</table>

5.4 Spanning Cells

Cell spanning allows a table cell to occupy more than one row or column.

Colspan: Combines multiple columns into one cell.

<table border="1">
    <tr>
        <th colspan="2">Student Details</th>
    </tr>
    <tr>
        <td>Name</td>
        <td>Aman</td>
    </tr>
</table>

Rowspan: Combines multiple rows into one cell.

<table border="1">
    <tr>
        <td rowspan="2">CSE</td>
        <td>HTML</td>
    </tr>
    <tr>
        <td>CSS</td>
    </tr>
</table>

5.5 Table Headers and Captions

The caption element provides a title or description for a table. The thead, tbody and tfoot elements organize the header, body and footer sections.

<table border="1">
    <caption>Student Marks</caption>
    <thead>
        <tr>
            <th>Name</th>
            <th>Marks</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Aman</td>
            <td>85</td>
        </tr>
    </tbody>
</table>

6. HTML Forms

6.1 Introduction to Forms

HTML forms are used to collect information from users. They allow users to enter data such as names, email addresses, passwords and feedback.

6.2 Creating a Form

The form element defines an HTML form. The action attribute specifies where the submitted data is sent, and the method attribute specifies how it is sent.

<form action="/submit" method="post">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name">

    <button type="submit">Submit</button>
</form>

6.3 Form Input Types

The input element allows users to enter different types of data.

  • text: Accepts ordinary text.
  • password: Accepts a password.
  • email: Accepts an email address.
  • number: Accepts numeric input.
  • radio: Allows selection of one option from a group.
  • checkbox: Allows selection of multiple options.
  • date: Allows selection of a date.
  • file: Allows a user to select a file.
  • submit: Creates a form submission button.
  • reset: Resets form fields to their initial values.

6.4 Textarea and Select

The textarea element provides a multi-line text input. The select element creates a dropdown list.

<textarea rows="4" cols="30">
Enter your message
</textarea>

<select>
    <option>CSE</option>
    <option>ECE</option>
</select>

6.5 Form Validation

Form validation checks whether the information entered by a user meets specified requirements before submission.

HTML provides built-in validation attributes such as required, minlength, maxlength, min, max and pattern.

<form>
    <input type="email"
           required
           placeholder="Enter email">

    <input type="text"
           minlength="3"
           required
           placeholder="Enter name">

    <button type="submit">Submit</button>
</form>

6.6 Form Buttons

  • Submit Button: Submits the form data.
  • Reset Button: Resets the form fields.
  • Button: Creates a general-purpose clickable button.
<button type="submit">Submit</button>
<button type="reset">Reset</button>
<button type="button">Click Me</button>

7. Frames and Multimedia

7.1 Introduction to Frames

Frames were traditionally used to divide a browser window into separate sections, with each section displaying a different HTML document. The old frameset and frame elements are obsolete in HTML5.

7.2 Introduction to Iframes

An iframe (Inline Frame) is used to embed another webpage or external content inside the current HTML document.

<iframe
    src="https://example.com"
    width="500"
    height="300"
    title="Example Website">
</iframe>

7.3 Embedding External Content

External content can be displayed inside a webpage using an iframe, subject to the external website's security and embedding permissions.

7.4 Adding Audio to HTML

The audio element is used to add sound files to a webpage. The controls attribute displays playback controls such as play, pause and volume.

<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>

7.5 Adding Video to HTML

The video element is used to display video files on a webpage.

<video width="500" controls>
    <source src="movie.mp4" type="video/mp4">
    Your browser does not support video.
</video>

7.6 Multimedia Controls

HTML provides attributes to control multimedia playback.

  • controls: Displays playback controls.
  • autoplay: Requests automatic playback.
  • loop: Repeats the media after it ends.
  • muted: Starts the media without sound.
  • poster: Specifies a preview image for a video.
  • preload: Gives the browser a hint about loading media.

7.7 Source Elements for Multiple Formats

The source element allows multiple media formats to be provided. The browser can select a format it supports.

<video controls width="400">
    <source src="movie.mp4" type="video/mp4">
    <source src="movie.webm" type="video/webm">
    Your browser does not support video.
</video>

7.8 Embedding YouTube Videos

YouTube videos can be embedded into webpages using an iframe. The video ID is included in the embed URL.

<iframe
    width="560"
    height="315"
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="YouTube video"
    allowfullscreen>
</iframe>

Replace VIDEO_ID with the actual ID of the YouTube video. The video owner's embedding settings must allow embedding.

8. Important Exam Points

  • Internet is a global network of interconnected networks.
  • WWW stands for World Wide Web.
  • ISP stands for Internet Service Provider.
  • DNS converts domain names into IP addresses.
  • HTML stands for HyperText Markup Language.
  • DOCTYPE declares the HTML document type.
  • HTML comments are not displayed in the browser.
  • Ordered lists use ol and unordered lists use ul.
  • Hyperlinks are created using the a tag.
  • Tables use table, tr, th and td elements.
  • Forms collect information from users.
  • Iframe embeds external content.
  • Audio and video elements add multimedia to webpages.
